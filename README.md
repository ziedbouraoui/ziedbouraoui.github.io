# Zied Bouraoui — academic website

Public address: https://ziedbouraoui.github.io/

A static academic website served from this repository by GitHub Pages. No build step, external service or JavaScript is required.

## Editing

- `index.html`: biography, research projects, publications, teaching, resources and contact.
- `styles.css`: typography, layout and responsive appearance.
- `assets/zied-bouraoui.jpg`: portrait.
- Previous section addresses redirect to the relevant section of the homepage.

Preserve the existing `advert/`, `images/` and older files under `assets/`; they may be referenced by older external links.

## Publication

Use the existing GitHub Pages deployment for this repository. The site files are at the root of the `main` branch. Keep any already-configured Pages source unchanged.

The prior ChatGPT Sites review copy is separate from this repository. Future updates should be published only here.

## Content

Initial research, teaching and contact material came from the previous personal website. Recent project dates were checked against the CRIL profile, and the selected 2025–2026 publications against their individual ACL Anthology pages. Expired job adverts are not presented as current.
